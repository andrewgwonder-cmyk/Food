РАЦИОН — установка на iPhone
============================

Что в архиве
  index.html            — само приложение
  foods.js              — встроенная база продуктов (~140 шт.)
  sw.js                 — офлайн-режим
  manifest.webmanifest  — название и иконка
  icon-*.png            — иконки

1. Выложить на GitHub Pages (один раз, лучше с компьютера)
  1) Зайдите на github.com, войдите в аккаунт (или создайте бесплатный).
  2) «+» вверху → New repository. Имя, например: racion. Public. Create repository.
  3) «uploading an existing file» → перетащите ВСЕ файлы из архива (не папку, а файлы) → Commit changes.
  4) Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save.
  5) Через 1–2 минуты обновите страницу: появится адрес вида https://ваш-логин.github.io/racion/

2. Поставить на iPhone
  1) Откройте адрес в Safari.
  2) «Поделиться» → «На экран "Домой"» → «Добавить».
  3) Первый запуск — с интернетом. Дальше работает без сети.
  Заполняйте дневник только в приложении с иконки: у Safari и у иконки разные хранилища.

3. Обновления
  Новые версии файлов загружаются в тот же репозиторий (Add file → Upload files, с заменой).
  В sw.js нужно поменять номер версии (racion-v1 → racion-v2), тогда телефон подтянет обновление
  при следующем запуске с интернетом.

4. Резервная копия
  Ещё → Резервная копия → «Сохранить копию» → «Сохранить в Файлы».
  Делайте раз в 1–2 недели и перед сменой телефона.
